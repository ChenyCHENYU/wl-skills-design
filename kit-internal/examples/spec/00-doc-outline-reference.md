## 关键规律（AI 参考）

1. **功能编码连续递增**：同一子模块内连续编号，PMOM 从 001 但跳过 005（业务决定）
2. **画面逻辑/处理逻辑用词不统一**：部分用「画面逻辑」，部分用「画面交互」，AI 生成时统一用「画面逻辑（原型）」
3. **4.x.3 对照表有时内嵌在 4.x.2 中**：如 `4.2.2.2 系统流程与作业画面对照表` 出现在流程说明章节内，属历史不一致，新文档应独立成 4.x.3
4. **API 章节通常简短**：多为「待定」或 2～3 行接口说明，不是文档主体

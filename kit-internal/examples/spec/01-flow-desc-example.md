## 4.1.2.2 PMMB-A-02 月度生产目标流程

### 流程说明

月度生产目标流程是在年度生产目标确定后，由计划部每月初根据年度目标、上月实绩及当月市场订单情况，分解制定当月各工序生产目标，经审核确认后下发至各工序执行的流程。

**流程编码**：PMMB-A-02  
**流程名称**：月度生产目标流程  
**所属子模块**：目标管理（PMMB）

### 活动说明表

| 活动编码 | 活动名称 | 执行角色 | 输入 | 输出 | 说明 |
|---------|---------|---------|------|------|------|
| PMMB-A-02-E-01 | 设定月度生产目标 | 计划部-生产计划员 | 年度生产目标、上月实绩数据、本月订单需求 | 月度生产目标草案 | 按轧线、钢种维度拆分年度目标；结合订单情况调整目标数量 |
| PMMB-A-02-E-02 | 月度生产目标审核 | 计划部-计划主管 | 月度生产目标草案 | 审核意见 | 审核是否合理，可驳回要求重新制定 |
| PMMB-A-02-E-03 | 修改月度生产目标 | 计划部-生产计划员 | 审核意见 | 修改后的月度生产目标 | 仅在审核驳回后执行此活动 |
| PMMB-A-02-E-04 | 月度生产目标确认 | 计划部-计划主管 | 修改后的月度生产目标草案 | 确认后的月度生产目标 | 审核通过后状态变更为「已确认」 |
| PMMB-A-02-E-05 | 下发月度生产目标 | 计划部-计划主管 | 确认后的月度生产目标 | 下发通知 | 系统推送至各工序生产负责人；同步更新月订单推估画面 |

## 格式说明（供 AI 参考）

### 标准节名称

```
4.x.2.y  [流程编码] [流程名称]

（一）流程说明
（二）活动说明表
```

> **注意**：原始华新文档中两部分在同一小节，不单独分节标题；生成时保持这种风格（不要加过多标题层级）。

### 活动说明表列定义

| 列名 | 必填 | 说明 |
|------|------|------|
| 活动编码 | ✅ | 格式：`[流程编码]-E-[NN]`，NN 从 01 开始 |
| 活动名称 | ✅ | 动词短语，如「设定月度生产目标」|
| 执行角色 | ✅ | 格式：`部门-岗位`，如「计划部-生产计划员」|
| 输入 | ✅ | 本活动所需要的信息/单据/数据 |
| 输出 | ✅ | 本活动完成后产生的信息/单据/数据 |
| 说明 | ⚪ | 补充说明（条件、规则、注意事项）|

### 活动编码规则

```
[流程编码]-E-[NN]

示例：
PMMB-A-02-E-01   ← 目标管理-流程A02-第01个活动
PMPM-A-01-E-03   ← 计划管理-流程A01-第03个活动
```

### 流程说明段落要点

流程说明（前导文字）应包含：
1. **是什么**：本流程的业务定义
2. **谁发起**：触发流程的角色/时机
3. **做什么**：流程完成什么业务目标
4. 一般 3～5 句话，不要过长

# 设备点检 接口设计 · 分册总览

## 接口清单

| 稳定 ID | 编码 | 接口名称 | 类型 | 协议 | 提供方 | 消费方 | 关联功能 ID | 字段 ID | 数据落点 |
|---------|------|---------|------|------|--------|--------|------------|---------|---------|
| EQM_IF_01 | EQM-IF-01 | 点检单分页查询 | RESTful | HTTPS | 设备服务 | 前端 | EQIP001 | EQM_F_DEVICE_CODE 等 5 项 | eqm_inspection_main（读） |
| EQM_IF_02 | EQM-IF-02 | 提交点检单 | RESTful | HTTPS | 设备服务 | 前端 | EQIP001 | EQM_F_INSPECTION_ID 等 4 项 | eqm_inspection_main / eqm_inspection_dtl（写） |

## 错误码清单

| HTTP 状态 | 稳定错误标识 | 含义 | 触发场景 | 处理建议 |
|-----------|-------------|------|---------|---------|
| 404 | EQM-V-001 | 点检单不存在 | id 无匹配 | 检查 id |
| 409 | EQM-B-001 | 状态不允许提交 | 非 DRAFT 状态提交 | 刷新后重试 |
| 400 | EQM-B-002 | 点检项为空 | 提交时无明细 | 至少录入一条点检项 |
| 500 | EQM-S-001 | 服务端异常 | 未捕获异常 | 重试或联系运维 |

## 安全说明

- 认证：Token（JWT），Header `Authorization: Bearer <token>`
- 写操作（提交）声明幂等键，重复提交返回首次结果
- 统一应答包装 `{code,msg,data,traceId}`，错误码格式 `[模块]-[类型]-[序号]`

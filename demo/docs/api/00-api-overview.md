# 设备点检 接口设计 · 分册总览

## 接口清单

| 接口编码 | 接口名称 | 类型 | 源→目标 | 关联 spec 功能编码 | 关联 DB 表 |
|---------|---------|------|---------|-------------------|-----------|
| EQM-IF-01 | 点检单分页查询 | RESTful | 前端→设备服务 | EQIP001 | eqm_inspection_order |
| EQM-IF-02 | 提交点检单 | RESTful | 前端→设备服务 | EQIP001 | eqm_inspection_order |

## 错误码清单

| 错误码 | 含义 | 触发场景 | 处理建议 |
|--------|------|---------|---------|
| EQM-V-001 | 点检单不存在 | id 无匹配 | 检查 id |
| EQM-B-001 | 状态不允许提交 | 非 DRAFT 状态提交 | 刷新后重试 |
| EQM-B-002 | 点检项为空 | 提交时无明细 | 至少录入一条点检项 |
| EQM-S-001 | 服务端异常 | 未捕获异常 | 重试或联系运维 |

## 安全说明

- 认证：Token（JWT），Header `Authorization: Bearer <token>`
- 写操作（提交）声明幂等键，重复提交返回首次结果
- 统一应答包装 `{code,msg,data,traceId}`，错误码格式 `[模块]-[类型]-[序号]`
